Write the demo script for: (the text the user gave after the command, or their request in the message)

Write it into `docs/PITCH.md`. The jury has about 15 minutes per team. Structure:
1. Problem (30 s): who suffers, how often, what it costs. Use concrete numbers if the material has them.
2. Solution in one sentence.
3. Live demo (5 min): the exact clicks and inputs, step by step, with the synthetic example data to use.
4. How it works (2 min): architecture in 4 boxes, which AI does what, how we check quality.
5. Responsible AI (2 min): sources shown, limits, human-in-the-loop, data protection.
6. Impact and next steps (1 min): time-to-impact, what a pilot needs.
7. Likely jury questions with short answers.

Then list the features the demo needs, ordered by demo order. Mark each as must, should or cut.
